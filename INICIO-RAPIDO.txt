UTN FRM MCP — GUÍA RÁPIDA PARA ESTUDIANTES
Beta 2.1.1 | Windows, Linux y macOS

Conecta Codex, Claude Code u OpenCode con el Campus Virtual, Autogestión y el correo de UTN Mendoza para consultar lo que tu cuenta ya puede ver. Es una beta de solo lectura: no entrega tareas, no escribe en foros ni se inscribe a nada (en el correo solo mueve a la Papelera y marca leído).
La guía completa está en el README: https://github.com/BautistaAlosMartorell/utnfrm-mcp (carpeta docs/)

1. REQUISITOS
Node.js 22.13 o posterior (https://nodejs.org/) y un cliente de IA con MCP ya instalado. Abre una terminal nueva y comprueba:
  node --version
  codex --version       (o: claude --version / opencode --version)

2. INSTALA
Opción A, con npm:
  npm install --global utn-mcp-mendoza@beta
  utn-mcp-mendoza install-browser

Opción B, descarga verificada. De https://github.com/BautistaAlosMartorell/utnfrm-mcp/releases/tag/v2.1.1 (sección “Assets”, no “Source code”) guarda en Descargas, en una carpeta “utn-mcp-beta”: utn-mcp-mendoza-2.1.1.tgz y utn-mcp-mendoza-2.1.1.tgz.sha256. Luego, en esa carpeta:

  Windows — PowerShell:
    cd "$HOME\Downloads\utn-mcp-beta"
    $esperado = (Get-Content .\utn-mcp-mendoza-2.1.1.tgz.sha256 -Raw).Trim().Split()[0]
    $obtenido = (Get-FileHash .\utn-mcp-mendoza-2.1.1.tgz -Algorithm SHA256).Hash.ToLower()
    if ($obtenido -eq $esperado) { "OK: archivo verificado" } else { "ERROR: vuelve a descargarlo" }
    npm install --global .\utn-mcp-mendoza-2.1.1.tgz
    utn-mcp-mendoza install-browser

  Linux:
    cd ~/Downloads/utn-mcp-beta
    sha256sum -c utn-mcp-mendoza-2.1.1.tgz.sha256
    npm install --global ./utn-mcp-mendoza-2.1.1.tgz
    utn-mcp-mendoza install-browser

  macOS:
    cd ~/Downloads/utn-mcp-beta
    shasum -a 256 -c utn-mcp-mendoza-2.1.1.tgz.sha256
    npm install --global ./utn-mcp-mendoza-2.1.1.tgz
    utn-mcp-mendoza install-browser

Si la verificación muestra “ERROR”, vuelve a descargar. En macOS, permite el acceso al Llavero si te lo pregunta.

Solo Linux: antes instala el almacén seguro, en una sesión gráfica normal y desbloqueada:
    Ubuntu / Debian:  sudo apt-get update && sudo apt-get install -y libsecret-tools gnome-keyring
    Fedora:           sudo dnf install -y libsecret gnome-keyring
    Arch:             sudo pacman -S --needed libsecret gnome-keyring
Si Chromium no abre por falta de bibliotecas: “utn-mcp-mendoza install-deps” (por pasos, muestra el comando y pide confirmación).

3. INICIA SESIÓN
  utn-mcp-mendoza login
Se abre una ventana con tres pestañas: Campus, Autogestión y Webmail. Escribe tu contraseña solo ahí y elige tu legajo en Autogestión; cuando entras a las tres (unos 5 minutos), las sesiones se guardan y la ventana se cierra sola. Comprueba con:
  utn-mcp-mendoza status      (Campus)
  utn-mcp-mendoza doctor      (los tres sitios)

Así el MCP nunca ve tu contraseña: solo guarda cookies cifradas. Si prefieres que renueve la sesión solo y que el correo use IMAP, carga usuario, contraseña y correo con “utn-mcp-mendoza setup-wizard” (opcional, cifrados por tu sistema; se borran con “utn-mcp-mendoza forget-credentials”). Si la sesión vence, repite “login”; no reinstales.

4. CONECTA TU CLIENTE
  Codex:       utn-mcp-mendoza setup-codex
  Claude Code: utn-mcp-mendoza setup-claude
  OpenCode:    utn-mcp-mendoza setup-opencode
Comprueba que aparezca “utn-mendoza” (codex mcp list | claude mcp list | opencode mcp list) y reinicia el cliente. Con --print solo muestra el comando. Si ya estaba registrado, quítalo primero (ver DESINSTALAR).

(Atajo: “utn-mcp-mendoza setup-wizard” hace los pasos 3 y 4 por ti.)

5. PRUEBA
  Lista mis materias y las tareas próximas. Si no hay resultados, dime que la lista está vacía; si hubo un error de acceso, explícame cuál.

“utn-mcp-mendoza --help” lista todos los comandos.

DESINSTALAR
  utn-mcp-mendoza logout
  utn-mcp-mendoza forget-credentials
  codex mcp remove utn-mendoza                (si usaste Codex)
  claude mcp remove utn-mendoza --scope user  (si usaste Claude Code)
  opencode mcp remove utn-mendoza             (si usaste OpenCode)
  npm uninstall --global utn-mcp-mendoza

SI ALGO FALLA
Ejecuta “utn-mcp-mendoza doctor” y comparte con quien te dio la beta: sistema operativo y versión, “node --version”, el paso y el mensaje de error. No envíes contraseñas, cookies, archivos de sesión, capturas del Campus ni datos académicos.
Qué está probado y qué no: ver docs/soporte.md en el repositorio (“Qué está probado”).
