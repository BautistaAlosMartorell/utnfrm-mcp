# UTN FRM MCP 2.0.0 — beta de solo lectura

Servidor MCP local por STDIO para consultar el Campus Virtual de UTN Mendoza desde Codex u otro cliente compatible.

- Inicio de sesión manual en Chromium y sesión local protegida en Windows.
- Lectura de materias, tareas, consignas, recursos, calificaciones, foros y calendario según los permisos de la cuenta.
- Lectura de documentos con indicación de extracción parcial; OCR opcional, sin descarga automática de modelos.
- Las escrituras y las entregas permanecen deshabilitadas.

Requiere Node.js 22.13 o posterior. Seguí los pasos de instalación de Windows en el README.
